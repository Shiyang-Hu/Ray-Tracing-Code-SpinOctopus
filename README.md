# SpinOctopus

**SpinOctopus** is a general-relativistic ray-tracing algorithm and application platform developed in Fortran and Python, specifically designed for axisymmetric spacetimes. Users only need to input the covariant metric tensor and task parameters to execute a wide variety of simulations.

For comprehensive details, please refer to the `Configuration Guide and Technical Documentation.pdf` and the inline code comments. You may also consult our arXiv preprint: 

> Shiyang Hu, Dan Li, Chen Deng, Lina Zhang, and Wenfu Cao, *SpinOctopus: A Versatile, User-Friendly, and Extensible Public Code for General-Relativistic Ray-Tracing in axisymmetric spacetime*.

Should you encounter any issues or have any questions during usage, please do not hesitate to contact us.
